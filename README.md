# XAUT CEX-DEX 套利监控系统

XAUT (Tether Gold) 中心化交易所与去中心化交易所之间的套利机会监控系统。

## 📋 项目概述

本项目用于监控 XAUT 在 OKX (CEX) 和 Uniswap (DEX) 之间的价格差异，分析套利机会，并提供风险评估。

### 主要功能

- 🔍 **实时价格监控**: 获取 OKX 和 Uniswap 的实时价格
- 💰 **套利机会计算**: 自动计算 CEX→DEX 和 DEX→CEX 的套利收益
- 📊 **流动性分析**: 评估 DEX 池子深度和价格影响
- ⚠️ **风险警告**: 识别高滑点、低流动性等风险
- 📈 **数据统计**: 记录历史价格数据和套利机会
- 🔔 **告警通知**: 发现盈利机会时发送通知

## 🚀 快速开始

### 1. 安装依赖

```bash
cd xaut-arbitrage-monitor
npm install
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 文件，填入你的 API 密钥和配置
```

需要配置的项目:
- `OKX_API_KEY` - OKX API Key
- `OKX_API_SECRET` - OKX API Secret
- `OKX_PASSPHRASE` - OKX Passphrase
- `ETH_RPC_URL` - Infura 或 Alchemy 的 RPC URL

### 3. 运行测试

```bash
npm test
```

这将测试所有模块的功能，验证 API 连接和配置是否正确。

### 4. 启动监控

**单次检查模式** (推荐首次运行):
```bash
npm run monitor -- --once
```

**持续监控模式**:
```bash
npm start
```

或:
```bash
npm run monitor
```

## ⚙️ 配置说明

### 监控参数

在 `.env` 文件中可以调整以下参数:

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `CHECK_INTERVAL_MINUTES` | 检查间隔 (分钟) | 1 |
| `MIN_SPREAD_PERCENTAGE` | 最小价差百分比 (触发告警) | 0.5 |
| `MIN_PROFIT_USD` | 最小利润 USD | 10 |
| `TEST_CAPITAL_ETH` | 测试资金规模 (ETH) | 1.5 |

### 告警配置 (可选)

```env
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

## ⚠️ 风险提示

1. **流动性风险**: DEX 池子流动性极低 (~$77K)，大额交易会吃掉整个池子
2. **价格波动**: 套利过程中价格可能发生变化
3. **Gas 费用**: 以太坊主网 Gas 费可能侵蚀利润
4. **智能合约风险**: DEX 合约可能存在漏洞
5. **提现延迟**: CEX 提现可能需要时间审核

## 🔧 技术栈

- **node-cron** - 定时任务
- **Winston** - 日志记录

可以使用这些数据进行:
- 历史价格分析

## 📝 注意事项

1. **API 限制**: OKX API 有频率限制，请勿设置过短的检查间隔
2. **RPC 限制**: Infura/Alchemy 免费版有请求次数限制
3. **资金安全**: 本脚本仅用于监控，不会执行任何交易
4. **合规性**: 请确保你的交易行为符合当地法规和交易所规定

## 🔍 调研结论

根据初步调研:

1. **DEX 流动性问题**: Uniswap 上 XAUT 池子流动性仅约 $77K，远低于 CEX
2. **价格差异**: 观察到的 DEX 价格 ($1,587) 与 CEX 价格 ($5,344) 存在巨大差异
3. **可能原因**:
   - 数据延迟或错误
   - 流动性枯竭
   - 旧合约地址问题 (XAUT 已迁移到新合约)

**建议**:
1. 先运行监控脚本观察一段时间
2. 用极少量资金测试实际成交价格
3. 确认 XAUT 新合约地址
4. 谨慎评估风险后再考虑执行套利
